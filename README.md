# Multichain dApps — лабораторная работа

Проект выполнен на **Next.js**, **TypeScript**, **Tailwind CSS** и **viem**. Используется тестовая сеть Ethereum Sepolia.

## Выполненные задания

1. Создание Next.js-приложения с TypeScript и Tailwind CSS.
2. Настройка `createPublicClient` и `createWalletClient` из `viem`.
3. Подключение кошелька MetaMask и чтение баланса (ETH и Wei).
4. Отправка нескольких GWei тестового ETH, отображение хеша транзакции и статуса подтверждения.
5. Чтение ERC-721: `name()`, `symbol()`, `ownerOf(tokenId)` для адреса из задания.
6. Самостоятельная работа: чтение другого контракта WETH (ERC-20) на Sepolia через собственный ABI: `name()`, `symbol()`, `decimals()`, `totalSupply()`.

## Запуск в Windows PowerShell

Необходим установленный Node.js (рекомендуется Node 22 или новее).

```powershell
npm install
npm run dev
```

Открыть в браузере `http://localhost:3000`. Команды запускать в папке, содержащей `package.json`.

## Выполнение практической части

1. Открыть в новом профиле Chrome браузер с MetaMask, настроить **Sepolia** (chain ID `11155111`).
2. Подключить **не скомпрометированный** кошелёк, предназначенный исключительно для тестов. Не публиковать секретную фразу или приватный ключ.
3. Нажать «Подключить и проверить баланс». Снять скриншот адреса и баланса.
4. Получить тестовый Sepolia ETH из легитимного faucet при необходимости (не использовать настоящую криптовалюту).
5. Указать публичный адрес тестового получателя и `3` GWei. Подписать транзакцию в MetaMask. Сохранить публичный хеш и скриншоты подтверждения.
6. Прочитать данные ERC-721 (если `ownerOf` возвращает ошибку, сначала убедиться в существовании выбранного tokenId).
7. Выполнить самостоятельное задание: нажать «Прочитать данные WETH», сохранить результат.
8. Собрать реальные скриншоты в папку `screenshots/`, составить отчёт по `ОТЧЕТ_ШАБЛОН.md`, отправить согласно требованию преподавателя на ELearn.

## Адреса примеров

- ERC-721 из методического файла: `0xae2a37b60b7af7fcca8167df617f82a34f22719c`.
- Второй публичный контракт ERC-20 WETH: `0x7b79995e5f793a07bc00c21412e50ecae098e7f9`.

Адрес ERC-721 приведён в задании преподавателя. Доступность токена с выбранным ID и ответы публичной сети следует проверить в запущенном приложении; мы не заявляем о проверенных ответах без фактического вызова.

## Структура

- `app/client.ts` — клиенты viem и проверка Sepolia.
- `app/walletComponent.tsx` — подключение кошелька и баланс.
- `app/transactionComponent.tsx` — отправка транзакции.
- `app/abi.ts` — ABI ERC-721 и ERC-20.
- `app/tokenComponent.tsx` — чтение первого контракта.
- `app/extraContractComponent.tsx` — самостоятельная работа по второму контракту.
- `app/page.tsx` — главная страница.
- `ОТЧЕТ_ШАБЛОН.md` — структура отчёта, который нужно заполнить подтверждёнными результатами.

**Ограничение:** это исходники проекта; папка `node_modules` не включена. Приложение нужно установить, запустить и проверить на своём компьютере. Автоматический build здесь не выполнялся, поскольку доступ к npm registry отсутствовал.
