# Первый запуск проекта (Windows)

1. Распакуйте ZIP-файл в удобную папку.
2. Откройте папку `Multichain_dApps_viem_RU` в Visual Studio Code через **File → Open Folder**.
3. Откройте **Terminal → New Terminal**.
4. Запустите `npm install`.
5. После успешной установки запустите `npm run dev`.
6. Откройте `http://localhost:3000` в Chrome с MetaMask.
7. Проверьте подключение к **Sepolia**. Hardhat Local (31337) здесь не подходит.
8. Для учебного взаимодействия используйте только тестовые средства; не используйте кошелёк, слова восстановления которого были раскрыты.
9. Сделайте реальные скриншоты после выполнения каждого этапа и дополните отчёт.

Если команды завершились с ошибкой, сохраните первую строку ошибки и последние 15 строк терминала, затем исправьте проблему перед сдачей.
